# TIMO 2026 - Khối 1

Website luyện tập và thi thử từ tài liệu do người dùng cung cấp: 14 đề, 350 câu, câu hỏi song ngữ và hình gốc; đáp án tham khảo và lời giải của FERMAT Education.

- Vòng loại: 7 đề trắc nghiệm, 25 câu/đề, 60 phút.
- Vòng quốc gia: 7 đề điền đáp án, 25 câu/đề, 90 phút.
- Luyện từng câu, thi đếm giờ, tự nộp, đánh dấu, trộn câu, xem kết quả theo chủ đề.
- Mỗi câu đúng: 4 điểm. Kết quả chỉ phục vụ luyện tập.

Mở index.html hoặc chạy python -m http.server 8766. Không cần cài thư viện hay build. GitHub Pages: main / root.

Câu điền đáp án so sánh với bảng đáp án: bỏ khoảng trắng, không phân biệt hoa/thường, hỗ trợ tên ngày, chẵn/lẻ và hình tròn/tam giác. Những cách viết tương đương khác cần đối chiếu lời giải. Tải lại trang sẽ mất lượt làm bài.

Tài liệu gốc thuộc FERMAT Education. Website không phải sản phẩm chính thức của TIMO hoặc FERMAT.
